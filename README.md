## Introduction
As a part of an assignment during my education for Fornt End Developer I had to create an SVG-file that I later could manipulate in GSAP. This is all built without any framework and is only built with Vanilla JavaScript, Vite as a builder and basic CSS styling. 

### Demo

![Gif animation flying in from left, right and below](make-it-pop.gif)



#### Description

I created the SVG-file via Adobe Illustrator where I wrote my text using the text tool to then make it into regular vector graphics. I saved is an SVG-file to my dekstop and opened it in Text Editor to see the SVG paths. 

The animation is purely built with GSAP and Vanilla JavaScript and is making out the three words "Make It Pop!" flying in from the left, the right and from below on a colorful gradient background.
